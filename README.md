### Markdown 문법 정리

| 문법 | 작성 예시 | 결과 |
|---|---|---|
| 제목 | `# 제목`, `## 소제목` | 제목 단계별 표시 |
| 굵게 | `**굵은 글씨**` | **굵은 글씨** |
| 기울임 | `*기울임 글씨*` | *기울임 글씨* |
| 취소선 | `~~취소선~~` | ~~취소선~~ |
| 인라인 코드 | `` `print("Hello")` `` | `print("Hello")` |
| 링크 | `[링크 이름](https://example.com)` | 링크 표시 |
| 이미지 | `![이미지 설명](이미지_URL)` | 이미지 삽입 |
| 순서 없는 목록 | `- 항목` | 글머리 기호 목록 |
| 순서 있는 목록 | `1. 항목` | 번호 목록 |
| 인용문 | `> 인용문` | 인용문 표시 |
| 구분선 | `---` | 가로 구분선 |
| 체크리스트 | `- [ ] 할 일`, `- [x] 완료` | 체크박스 목록 |

코드 블록은 백틱 세 개로 감싸고, 필요하면 언어 이름을 붙입니다.

```python
print("Hello, Markdown!")
```
